Full index prefixes in combinatorial sequences and simultaneous digit windows

Download PDF (31 pp) LaTeX source (.tex) GitHub folder

Abstract

For every fixed pair of integers \(s, t\), the binary expansion of \(\binom{2n+s}{n+t}\) begins with the entire expansion of \(n\) at a number of indices in \([X, X^{3/2+\varepsilon}]\) tending to infinity. An analogous result holds for centered, strongly aperiodic planar lattice walks with a power of two labeled steps. Up to \(X\) both families have at least a constant times \((\log\log X)(\log\log\log X)\) matches.

For counts asymptotic to \(C b^{hn} n^{1-p}(1 - \gamma/n + O(n^{-2}))\), we classify the integer radices admitting a zero-entropy survivor for the associated circle map: there are exactly seven, each realized by an unshifted count. The arithmetic argument also yields exact Hausdorff dimensions for long simultaneous zero blocks on an algebraic line, showing that synchronizing two multiplicatively independent radices strictly lowers the critical block exponent. For integer-valued polynomials we decide when the index occurs as both prefix and suffix infinitely often (with universal finiteness for \(n^d+c\)). In Zeckendorf notation the large indices prefixing \(n^2+c\) are exactly the Lucas numbers \(L_k\) with \(c + 2(-1)^k \ge 0\).

Main Formulas

$$U_n = C\, b^{hn}\, n^{1-p}\!\left(1 - \frac{\gamma}{n} + O(n^{-2})\right) \quad\Longrightarrow\quad \text{zero-entropy radices } b \in \{2, 3, 4, 8, 9, 16, 32\}.$$ $$H_2\!\left(\binom{2n+s}{n+t};\, 1, X\right) \gg (\log\log X)(\log\log\log X).$$
