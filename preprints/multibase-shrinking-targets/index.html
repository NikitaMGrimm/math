Simultaneous shrinking targets on the diagonal in several integer bases

Download PDF (21 pp) LaTeX source (.tex) GitHub folder

Abstract

We determine the local Hausdorff dimension of simultaneous shrinking targets for integer radix maps restricted to a scalar diagonal or an algebraic line. For multiplication by two and three, with common radius \(\psi(n) \le 1\) of lower exponential order \(\tau = \liminf_{n\to\infty} (-\log\psi(n))/(n\log 3)\), each target \(y \in \mathbb{T}^2\) has dimension \((1-\tau)/(1+\tau)\) when \(0 \le \tau < 1\), and dimension zero thereafter. This removes the \(abc\) hypothesis in a result of Li, Liao, Velani, and Zorin (Adv. Math. 2023, §5.5, Remark 13). Explicit counterexamples refute both sides of printed Eq. (75) at \((2,17)\) and \((2,6)\).

For radii \(3^{-n\tau}\), a single residual set of transcendental slopes gives binary–ternary zero-target dimension \(\log_3(2)/(1+\tau)\) throughout \(1 - \log_3(2) < \tau \le 1\), refuting the all-bi-Lipschitz suspicion at \(\tau = 1\); we compute the Hausdorff dimension of the slope sets at each exceptional fiber dimension. For finitely many radices sampled at arbitrary relative speeds, a partition weighted by prime valuations gives the homogeneous dimension. Translations preserve this dimension in coprime bases; for shared primes, the exact formula uses intersections of translated grid intervals, with bases \((2,6)\) realizing a full interval of dimensions as a single target coordinate varies.

Main Formulas

$$\dim_H E_{2,3}(y;\psi) = \begin{cases} \dfrac{1-\tau}{1+\tau}, & 0 \le \tau < 1, \\[8pt] 0, & \tau \ge 1, \end{cases} \qquad \forall\, y \in \mathbb{T}^2.$$
