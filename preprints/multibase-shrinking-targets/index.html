Simultaneous shrinking targets on the diagonal in several integer bases

Download PDF (21 pp) LaTeX source (.tex) GitHub folder

Abstract

We determine the local Hausdorff dimension of simultaneous shrinking targets for integer radix maps restricted to a scalar diagonal or an algebraic line. For multiplication by two and three, with common radius of lower exponential order τ in base three, each target has dimension (1−τ)/(1+τ) when 0 ≤ τ < 1, and dimension zero thereafter. This removes the abc hypothesis in a result of Li, Liao, Velani, and Zorin (Adv. Math. 2023, §5.5, Remark 13). Explicit counterexamples refute both sides of printed Eq. (75) at (2, 17) and (2, 6).

For radii 3−nτ, a single residual set of transcendental slopes gives binary–ternary zero-target dimension log3(2)/(1+τ) throughout 1 − log3(2) < τ ≤ 1, refuting the all-bi-Lipschitz suspicion at τ = 1; we compute the Hausdorff dimension of the slope sets at each exceptional fiber dimension. For finitely many radices sampled at arbitrary relative speeds, a partition weighted by prime valuations gives the homogeneous dimension. Translations preserve this dimension in coprime bases; for shared primes, the exact formula uses intersections of translated grid intervals, with bases (2, 6) realizing a full interval of dimensions as a single target coordinate varies.
